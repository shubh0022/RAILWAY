# RAILWAY — IRCTC Rail Connect Next-Gen Redesign

Your journey, just a tap away. Experience India's next-gen booking platform. Instant search, transparent seat pricing, and 100M+ user capacity.

This is a modern rebuilt version of IRCTC Rail Connect with ultra-fast search, robust caching, virtual seat lock queues, and offline synchronization capabilities.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **State Management**: Zustand
- **Icons**: Lucide React

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
